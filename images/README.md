# Images

Drop real artwork into this folder using the filenames referenced in the HTML.
If a file is missing, the page falls back to a stylized SVG/glyph placeholder.

## Referenced filenames

**Home (`index.html`)**
- `hero-shiva.jpg` — large hero canvas (3:4)
- `series-adiyogi.jpg`, `series-devi.jpg`, `series-shiva-shakti.jpg`,
  `series-naga.jpg`, `series-sahasrara.jpg`, `series-manasarovar.jpg` — series cards (3:4)

**Works (`works.html`)**
- `work-01.jpg` … `work-09.jpg` — gallery thumbnails (3:4)

**Series (`series.html`)**
- Re-uses the `series-*.jpg` files above (4:5 display)

**About (`about.html`)**
- `portrait.jpg` — artist portrait (3:4)

## Recommended specs
- Format: JPG or WebP, sRGB
- Aspect ratio: roughly 3:4 (works/cards) or 4:5 (series rows)
- Long edge: 1400–1800px is plenty for web
